# Un cuore per te ❤️

Piccolo sito romantico, ottimizzato per smartphone, con un cuore animato formato da "Ti amo" in 20 lingue. Funziona su GitHub Pages senza server Python e senza installare dipendenze.

## Pubblicarlo su GitHub Pages

1. Crea su GitHub un nuovo repository (esempio: `un-cuore-per-te`). Per usare GitHub Pages con il piano gratuito, rendilo **Public**.
2. Carica nella **cartella principale** del repository `index.html` e, se vuoi, `.nojekyll` e `README.md`. Non caricare solo il file ZIP: prima estrailo.
3. Apri **Settings → Pages** nel repository.
4. In **Build and deployment** seleziona **Deploy from a branch**.
5. Imposta **Branch: main**, cartella **/(root)** e premi **Save**.
6. Attendi che GitHub segnali il sito come pubblicato; l'indirizzo sarà simile a `https://TUO-USERNAME.github.io/un-cuore-per-te/`.
7. Aprilo sul telefono e invia il collegamento alla persona a cui è dedicato.

## Modifiche

Per cambiare le frasi, apri `index.html` con VS Code e modifica l'array `LOVE` nella parte JavaScript. Puoi modificare il titolo della scheda nel tag `<title>`.

Il cuore si disegna automaticamente all'apertura. Toccandolo, o premendo "Rivedi l'animazione", ricomincia.

**Nota:** il sito è pubblico su GitHub Pages: chiunque conosca il link può aprirlo. Non inserirvi dati riservati.
